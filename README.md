# Seoulify — K-Pop Merchandise Store

Seoulify is a K-pop merchandise shopping website developed as a web development portfolio project. It allows users to explore merchandise and interact with shopping features through a user-friendly interface.

## Features

- Browse K-pop merchandise
- View product details
- Add products to the shopping cart
- User registration and login
- Daily login rewards and SPoints wallet
- MySQL database integration for user accounts

## Technologies Used

**Frontend**
- React
- JavaScript
- HTML & CSS

**Backend**
- Java
- Spring Boot
- MySQL

## Getting Started

### Prerequisites
- Node.js and npm
- Java Development Kit (JDK)
- MySQL

### Frontend Setup
1. Clone or download this repository.
2. Open the frontend project folder in your terminal.
3. Install the dependencies:

   `npm install`

4. Start the development server:

   `npm start`

### Backend Setup
1. Open the Spring Boot backend project.
2. Configure the MySQL database connection.
3. Run the Spring Boot application.

## Project Status

This project is currently under development. Some features and backend integrations may still be in progress.

## Purpose

This project was created to practise frontend development, backend integration, database management, and user authentication.
